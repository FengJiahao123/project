# AI 小说转剧本工具 — 设计文档

> 日期：2026-06-05
> 状态：已确认

## 1. 项目概述

将 3 个章节以上的小说文本自动转换为结构化剧本（YAML 格式），帮助作者快速获得可编辑、可进一步打磨的剧本初稿。

## 2. 技术选型

| 层级     | 技术                    | 理由                                    |
| -------- | ----------------------- | --------------------------------------- |
| 后端     | Python + FastAPI        | LLM 生态成熟，异步支持好，API 开发简洁  |
| 前端     | React + TypeScript + Tailwind CSS | 组件化清晰，Demo 展示效果好     |
| AI 引擎  | 抽象 LLM Provider 接口  | 预留接口层，后续可灵活切换 API          |
| 项目管理 | uv + Vite               | 现代包管理，开发体验好                  |

## 4. 核心数据模型：剧本 YAML Schema

```yaml
meta:
  title: "剧本标题"
  original_work: "原著小说名"
  original_author: "原著作者"
  adapter: "改编者"
  version: "1.0"

characters:
  - id: "char_001"
    name: "角色名"
    role: "主角"            # 主角 / 配角 / 龙套
    description: "身份背景描述"
    traits: ["标签1", "标签2"]
    relationships:
      - target: "char_002"
        relation: "关系描述"

scenes:
  - scene_number: 1
    location:
      name: "场景地点"
      time: "时间"
      description: "环境描述"
    characters_present: ["char_001", "char_002"]
    elements:
      - type: "action"            # action / dialogue / transition
        content: "动作描述"
      - type: "dialogue"
        speaker: "char_001"
        lines:
          - "台词行1"
          - "台词行2"
        emotion: "情绪"
        notes: "表演备注"
      - type: "transition"
        content: "转场描述"
```

### Schema 设计原则

1. **elements 混合排列**：对话、动作、转场按时间顺序混排在同一数组，遍历即可还原完整演出流程，避免多数组同步索引的复杂度。
2. **characters_present 预声明**：每个场景预先列出在场角色，避免阅读中推断，方便灯光/道具组定位。
3. **角色 ID 引用**：dialogue.speaker 引用 characters[].id，保持引用一致性，允许角色改名而不破坏对话关联。
4. **YAML 格式**：可读性强、支持注释、业界标准配置格式，方便人工编辑与版本管理。

## 5. LLM 抽象层设计

```python
from typing import Protocol

class LLMProvider(Protocol):
    async def convert_chapter(
        self, chapter_title: str, chapter_text: str, schema_spec: str
    ) -> dict:
        """将单个章节转换为剧本片段（dict 格式，后续序列化为 YAML）"""
        ...
```

- 核心逻辑只依赖 `LLMProvider` 协议，不依赖任何具体 SDK
- 更换 API 只需新增一个实现类，业务代码零改动
- 初始实现使用占位 Provider（返回 mock 数据），确保前后端联调先行

## 8. 错误处理策略

- **后端**：章节分块失败 → 返回明确错误信息 + 建议（如"未检测到章节标题"）；LLM 调用超时 → 重试 1 次 + 返回部分结果；Schema 校验失败 → 返回具体校验错误位置
- **前端**：输入为空 → 按钮置灰 + 提示；转换中网络异常 → 显示错误 Toast + 重试按钮；结果解析失败 → 保留原始文本 + 降级展示
